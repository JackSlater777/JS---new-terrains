*********************************
!!!!! WARNING !!!!!
This mod requires JS - map generation fixes!
*********************************
If you are playing without JS - new objects:
go to
\Mods\JS - new terrains\Lang\
and "disable" the file `jsNT_jsNO_RMG_CustomizeObjectProperties.json`
by appending `.off` to its file extension.
Alternatively, you can add an empty `jsNT_jsNO_RMG_CustomizeObjectProperties.json` file to the `/lang/` folder within your own mod directory.
This will overwrite the existing file.
*********************************

This mod adds highlands terrain. It's a native terrain for conflux.

Also, this mod gives a possibility to add a new terrain via json-file and adding required resource files (sounds, def's, etc).
